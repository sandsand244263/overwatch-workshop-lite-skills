> 阅读提醒：本文档所有代码块里的 `#` 行都是**给人看的注解，不是工坊语法**。真实 `.ow` 文件的注释只有三种写法：`// 注释`、`"注释"`（仅限动作/条件块内）、`/* 注释 */`（详见 `diagnostics.md`）。生成代码时不要把 `#` 注解抄进去。

## 最小可运行文件模板

新建 `.ow` 文件时的规范骨架（插件"新建文件"生成的就是这个结构）：

```ow
设置
{
    主程序
    {
        模式名称: "新建模式"
        描述: "由 Overwatch® Workshop 创建的文件模版"
    }

    模式
    {
        死斗
    }
}

规则("你好，世界！")
{
    事件
    {
        持续 - 全局;
    }

    条件
    {
        "按下按钮来打个招呼"
        按钮被按下(主机玩家, 按钮(互动)) == 真;
    }

    动作
    {
        大字体信息(主机玩家, 自定义字符串("你好，世界！"));
    }
}
```

## 变量高级设计模式

### ⚠️ 数组 1-indexed 访问陷阱

通过 `添加至数组` 追加元素后，读取队首必须用 `[1]`，**不可用 `[0]` 或 `首个()`**。

```ow
修改玩家变量(事件玩家, PendingMessages, 添加至数组, 新消息);
事件玩家.PendingMessages[1]   # ✅ 正确
事件玩家.PendingMessages[0]   # ❌ 错误
```

### 属性分层数组（RPG核心模式）

```ow
# GJ[0]=基础攻击  GJ[1]=固定加成  GJ[2]=基础倍率  GJ[3]=额外倍率
最终伤害 = (GJ[0] + GJ[1]) * (GJ[2] + GJ[3])

事件玩家.GJ[0] += 8;   # 天赋加固定值
事件玩家.GJ[2] += 1;   # 天赋加倍率
设置造成伤害(事件玩家, (事件玩家.GJ[0] + 事件玩家.GJ[1]) * (事件玩家.GJ[2] + 事件玩家.GJ[3]));
```

### 数组嵌套多属性实体

```ow
# 一个槽位存多字段：数组(类型, 数量, 状态)
全局.items[n] = 数组(点数, 花色);
全局.items[n][0]   # 读点数
全局.items[n][1]   # 读花色
已排序的数组(全局.items, 当前数组元素[0])   # 按第一字段排序
```

### ID反查索引

```ow
# 构建逻辑ID→数组索引的映射，用 数组值的索引 实现 O(n) 反查
全局.cm_buttons_idsuoyin = 空数组;
For 全局变量(i, 0, 数量(全局.cm_Buttons), 1);
    修改全局变量(cm_buttons_idsuoyin, 添加至数组, 全局.cm_Buttons[全局.i][1]);
End;
# 使用：全局.cm_Buttons[数组值的索引(全局.cm_buttons_idsuoyin, buttonId)][字段]
```

### 平行数组实体系统（-1 哨兵空位）

```ow
# 初始化
全局.itemCode = 映射的数组(全局.ITEM_SLOTS, -1);

# 找空位并写入
全局.idx = 数组值的索引(全局.itemCode, -1);
If(全局.idx == -1);
    全局.idx = 数量(全局.itemPosition);
End;
在索引处设置全局变量(itemPosition, 全局.idx, 生成坐标);
在索引处设置全局变量(itemCode, 全局.idx, 物品类型);
创建效果(...);
在索引处设置全局变量(itemEffectID, 全局.idx, 最后创建的实体);

# 销毁：消除效果后将 itemCode[idx] 置 -1 释放槽位
消除效果(全局.itemEffectID[全局.idx]);
在索引处设置全局变量(itemCode, 全局.idx, -1);
```

## 控制流

```ow
If(条件); ... Else If(条件); ... Else; ... End;

While(条件);
    动作;
    等待(0.016, 无视条件);
End;

For 全局变量(控制变量, 起始值, 终止值, 步长); ... End;
For 玩家变量(控制玩家, 控制变量, 起始值, 终止值, 步长); ... End;

中断   # 跳出While（不能跳出For）
继续   # While循环跳到下一迭代
中止   # 停止整个动作列表

# For循环提前退出（用跳过模拟break）
根据条件跳过(条件, 100);   # 跳过足够多的行数退出循环
```

### 等待参数语义

> 注意：函数名里的引号必须是中文弯引号 `“ ”`（U+201C / U+201D），用英文直引号会导入报错。
```ow
等待(秒数, 无视条件)           # 无论如何都等
等待(秒数, 当为“假”时中止)     # 等待期间任一条件变假→整个动作列表立即中止
等待(秒数, 当为“真”时重新开始) # 等待期间条件仍为真→重置计时，条件变假→放行
等待直到(条件, 超时秒数)       # 等到条件满足或超时
```

## 复制进游戏时的「无 / 全部禁用」差异

插件编辑器允许在某些刷新参数位写 `无`，但**游戏内的导入文本要求写 `全部禁用`**（插件导出/导入时会自动替换）。我们生成的代码通常直接粘进游戏，所以下面这些位置一律写 `全部禁用`：

| 函数 | 参数位 |
|---|---|
| `创建HUD文本` `创建地图文本` `创建进度条HUD文本` `创建进度条地图文本` | 刷新参数 |
| `追踪全局变量频率` `追踪玩家变量频率` `持续追踪全局变量` `持续追踪玩家变量` `开始治疗调整` | 最后一个刷新参数 |
| `设置不可见` | 可见参数 |

其它刷新位照旧写 `无`，游戏直接认：`效果刷新`、`图标刷新`、`加速刷新`、`朝向刷新`、`阈值刷新`、`伤害调整刷新`、`助攻刷新`。
