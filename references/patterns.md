## 代码质量要求

1. 分号、缩进、括号完整；只使用合法函数名
2. 所有关键字用中文
3. `如条件为“真”则循环` 前必须有 `等待()`；While 中必须有 `等待(0.016, 无视条件)`
4. 使用变量须在 `变量 { }` 中声明，子程序须在 `子程序 { }` 中声明
5. 避免高频轮询，持续规则至少 `等待(0.100, 无视条件)`
6. 用 `比赛结束`(0)、`比赛回合`(1) 代替魔法数字
7. 创建 HUD 后立即用 `上一个文本ID` 存变量
8. `创建HUD文本` 有三槽（标题/子标题/文本），不需要的填 `空`
9. HUD 可见性优先用 `本地玩家` 或 `条件 ? 本地玩家 : 空`
10. 属性变更后立即调用 `设置造成伤害` / `设置最大生命值` 等同步
11. 更新生命池：先 `移除玩家的生命池(旧ID)` → 重新添加 → 保存新 `最后创建的生命池`
12. 元素上限 32768；单条规则上限 98KB；变量/子程序各最多 128 个

## 核心设计模式

### 单次赋值 vs 逐帧更新（性能关键）

```ow
# 位置固定→单次赋值（创建时计算一次）
创建地图文本(可见, 文本, 单次赋值(基准矢量 + 方向 * 行偏移), 3.4, 不要截取, ...);

# 位置跟随玩家→逐帧更新
创建地图文本(可见, 自定义字符串("╋"),
    逐帧更新(眼睛位置(本地玩家) + 面朝方向(本地玩家) * 100), 4, 不要截取, ...);

# ⚠️ For循环内创建持久效果时，循环变量做索引的参数必须包裹单次赋值
For 全局变量(i, 0, 数量(全局.Buttons), 1);
    创建效果(..., 全局.Buttons[单次赋值(全局.i)][4], ...);   # ✅
    # 创建效果(..., 全局.Buttons[全局.i][4], ...);           # ❌ 循环结束后全用最终值
End;

# ⚠️ 追踪变量的目标值若含动态表达式必须逐帧更新
追踪玩家变量频率(事件玩家, A,
    逐帧更新(按钮被按下(事件玩家, 按钮(跳跃)) ? 矢量(0,1,0) : 矢量(0,0,0)),
    6, 速率及最终值);

# ⚠️ While循环中同次迭代创建多个效果：ID存储必须在 i += n 之前
While(全局.i < 50);
    创建效果(...);
    全局.ID[单次赋值(全局.i)] = 最后创建的实体;     # ✅ 先存
    创建效果(...);
    全局.ID[单次赋值(全局.i) + 1] = 最后创建的实体; # ✅ 先存
    全局.i += 2;                                      # 最后才递增
End;
```

### 第三人称视角切换

```ow
规则("开启TPS")
{
    事件 { 持续 - 每名玩家; 双方; 全部; }
    条件 { 正在交流(事件玩家, 终极技能状态) == 真; }
    动作
    {
        If(事件玩家.AE == 0);
            开始镜头(事件玩家,
                事件玩家 + 上 * 1.500 + 面朝方向(事件玩家) * -4,
                事件玩家 + 面朝方向(事件玩家) * 1000,
                0);
            事件玩家.AE = 1;
        Else;
            停止镜头(事件玩家);
            事件玩家.AE = 0;
        End;
        等待(1, 无视条件);
    }
}
```

### 密码输入保留混淆层

```ow
# 若原方案已使用 syntax.md 中的数值混淆，不要改成明文字符或直接按钮序列
# 输入阶段直接记录“混淆后的码”，匹配阶段直接对比混淆码数组

# 从键位映射表中找出本次按下的是哪个真实按键值

    已过滤的数组(全局.GlobalKeyMapping, 按钮被按下(事件玩家, 当前数组元素)),

# 对比阶段直接比较“混淆码数组”与“混淆密码表”
If(事件玩家.PasswordInputCodes == 全局.SecretTitlePasswordTable[事件玩家.TargetIndex]);
    调用子程序(PasswordGrantTitle);
End;
```

### 常驻装饰对象生命周期

```ow
# 创建时保存实体 ID；资格失效时显式回收；恢复资格后允许重建
规则("管理员装饰创建")
{
    事件 { 持续 - 每名玩家; 双方; 全部; }
    条件
    {
        事件玩家.AdminWhitelistMark == 真;
        事件玩家.VisualInit[0] != 真;
    }
    动作
    {
        创建效果(所有玩家(所有队伍), 环, 颜色(黄色), 事件玩家, 1, 可见，位置和半径);
        事件玩家.VisualEffectIds[0] = 最后创建的实体;
        事件玩家.VisualInit[0] = 真;
    }
}

规则("管理员装饰回收")
{
    事件 { 持续 - 每名玩家; 双方; 全部; }
    条件
    {
        事件玩家.AdminWhitelistMark != 真;
        事件玩家.VisualInit[0] == 真;
    }
    动作
    {
        消除效果(事件玩家.VisualEffectIds[0]);
        事件玩家.VisualEffectIds[0] = 空;
        事件玩家.VisualInit[0] = 假;
    }
}
```
