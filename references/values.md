## 内置 `字符串(...)` 词条

`字符串(...)` 只能用内置预设词条，**完整 611 条清单见 `strings.md`**（45 条带 `{0}`~`{2}` 的格式模板 + 566 条固定词条）。常用词条示例：

```ow
字符串("警告")                             # 固定词条，不带额外参数
字符串("{0} 已消灭 {1}", 事件玩家, 被攻击方)   # 格式模板，按顺序补参数
字符串("{0} 米")  字符串("{0} 秒")  字符串("{0}%")  字符串("{0}:{1}")
```

`字符串()` 不能自由填内容；要拼自己的文字用 `自定义字符串(...)`，占位符上限 `{2}`，超出就嵌套。

```ow
自定义字符串("{0}{1}{2}", A, B, C)
```
