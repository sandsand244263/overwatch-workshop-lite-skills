# 内置 `字符串(...)` 预设词条全量清单（共 616 条）

工坊的 `字符串(...)` 只能从内置预设里挑，不能自己填内容；要自由拼字必须用 `自定义字符串(...)`。
本文件列出全部预设词条，数据来自游戏本体：用 [overtools/OWLib](https://github.com/overtools/OWLib) 的
`list-workshop` 命令从国服 2.25.0.0.154461 客户端导出（`TextOptions` 字段，去重后）。

## 用法

```ow
字符串("警告")                              # 固定词条：不带额外参数
字符串("{0} 米", 事件玩家)                    # 格式模板：按 {0}/{1}/{2} 顺序补参数
```

- 固定词条（无占位符）共 569 条，照抄即可。注意这里只有"词"，没有成句的模板：像 `"{0} 已消灭 {1}"`、`"回合 {0}"`、`"第 {0} 名"` 这类看着自然的句子**并不存在**，写了会导入失败。
- 格式模板（含占位符）共 47 条，其中最多只到 `{2}`：全部词条里没有 `{3}` 及以上的模板；要拼 4 段以上必须嵌套 `自定义字符串(...)`。
- 顺序沿用游戏数据顺序（近似游戏内下拉框顺序）。
- 游戏源数据里有重复条目（原始 725 条，去重后 616 条），本表已去重。

### 与旧版（插件数据）的差异

本次以游戏一手数据重导，以下 7 条在游戏里已改名或取消，**不要再使用**：

| 旧词条 | 现况 |

| `"孵化"` `"已孵化"` `"正在孵化"` | 改为 `"生成"` `"已生成"` `"正在生成"` |

| `"{0}%"` | 游戏数据里是 `"{0}%%"`（原始格式串与显示形式的差异，实际写法以游戏内下拉为准） |
| `"终点"` | 已取消 |

新增 12 条：`"GG"`、`"敏捷"`、`"无"`、`"生成"`、`"已生成"`、`"正在生成"`、`"正在洗牌"`、`"未解锁"`、`"第{0}回合"`、`"{0} - {1} - {2}"`、`"{0}%%"`、`"胜利：%1$s 经验"`。
