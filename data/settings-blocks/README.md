# 设置块模板

| 文件 | 适用 | 特征 |
|---|---|---|
| deathmatch.ow | 死斗 / 自由混战 | 无队伍上限；综合 7 键 |
| team.ow | 团队通用 | 有 玩家上限 队伍1/2 |
| control_occupation.ow | 占领要点 | 多模式开关 + 职责限制 |
| escort.ow | 攻击/护送 | 同上 |
| push.ow | 机动推进 | 同上 |
| bounty_hunter.ow | 赏金猎手（FFA） | 无花括号条目，没有任何可调项 |
| hero_level.ow | 英雄级设置 | 英雄 > 综合 与 英雄 > 英雄名 同级 |

## 写法规则（全部实测）

- 模式块里，当前模式直接写名字加花括号；不启用的模式写成 禁用 XXX { ... }
- 像 赏金猎手 这种没有可调项的模式，是**单行无花括号**条目：直接写 赏金猎手
- 职责限制写成 1重装，2输出，2支援（中文逗号）
- 英雄级设置与模式同级：英雄 { 综合 { 伤害量: 150% } D.Mon { 伤害量: 150% } }
- 布尔项只能写 开启 / 关闭；数值带百分号
- 设置块只整块复制，不要手拼层级；改完跑 ws.py check 复核
