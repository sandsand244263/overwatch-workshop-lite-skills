# 设置块模板

| 文件 | 适用 | 特征 |
|---|---|---|
| `deathmatch.ow` | 死斗/自由混战 | 无 `玩家上限 队伍1/2`；`综合` 含 7 键（含 随机英雄复生、允许切换英雄） |
| `team.ow` | 团队模式 | 有 `玩家上限 队伍1/2`；`综合` 键集较少 |

## 规则

- 设置块**只整块复制**，不要手拼层级——层级关系数据里没有，靠不住
- 换模式类型要换整份模板，不要在一份上加减键
- 布尔项只能写 `开启` / `关闭`（导出器写 `启用`/`禁用` 是历史 BUG，导入会失败）
- 改完跑 `python tools/ws.py check` 复核
