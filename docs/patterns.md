## 代码质量要求

1. 分号、缩进、括号完整；只使用合法函数名
2. 所有关键字用中文
3. `如条件为“真”则循环` 前必须有 `等待()`；While 中必须有 `等待(0.016, 无视条件)`
4. 使用变量须在 `变量 { }` 中声明，子程序须在 `子程序 { }` 中声明
5. 避免高频轮询，持续规则至少 `等待(0.100, 无视条件)`
6. 用 `比赛结束`(0)、`比赛回合`(1) 代替魔法数字
7. 创建 HUD 后立即用 `上一个文本ID` 存变量
8. `创建HUD文本` 有三槽（标题/子标题/文本），不需要的填 `空`
9. HUD 可见性优先用 `本地玩家` 或 `条件 ? 本地玩家 : 空`
10. 属性变更后立即调用 `设置造成伤害` / `设置最大生命值` 等同步
11. 更新生命池：先 `移除玩家的生命池(旧ID)` → 重新添加 → 保存新 `最后创建的生命池`
12. 元素上限 32768；单条规则上限 98KB；变量/子程序各最多 128 个（细节与可控部分见 `limits.md`）

## 核心设计模式

### 单次赋值 vs 逐帧更新（性能关键）

```ow
# 位置固定→单次赋值（创建时计算一次）
创建地图文本(可见, 文本, 单次赋值(基准矢量 + 方向 * 行偏移), 3.4, 不要截取, ...);

# 位置跟随玩家→逐帧更新
创建地图文本(可见, 自定义字符串("╋"),
    逐帧更新(眼睛位置(本地玩家) + 面朝方向(本地玩家) * 100), 4, 不要截取, ...);

# ⚠️ For循环内创建持久效果时，循环变量做索引的参数必须包裹单次赋值
For 全局变量(i, 0, 数量(全局.Buttons), 1);
    创建效果(..., 全局.Buttons[单次赋值(全局.i)][4], ...);   # ✅
    # 创建效果(..., 全局.Buttons[全局.i][4], ...);           # ❌ 循环结束后全用最终值
End;

# ⚠️ 追踪变量的目标值若含动态表达式必须逐帧更新
追踪玩家变量频率(事件玩家, A,
    逐帧更新(按钮被按下(事件玩家, 按钮(跳跃)) ? 矢量(0,1,0) : 矢量(0,0,0)),
    6, 速率及最终值);

# ⚠️ While循环中同次迭代创建多个效果：ID存储必须在 i += n 之前
While(全局.i < 50);
    创建效果(...);
    全局.ID[单次赋值(全局.i)] = 最后创建的实体;     # ✅ 先存
    创建效果(...);
    全局.ID[单次赋值(全局.i) + 1] = 最后创建的实体; # ✅ 先存
    全局.i += 2;                                      # 最后才递增
End;
```

### 第三人称视角切换

```ow

{
    事件 { 持续 - 每名玩家; 双方; 全部; }
    条件 { 正在交流(事件玩家, 终极技能状态) == 真; }
    动作
    {
        If(事件玩家.AE == 0);
            开始镜头(事件玩家,
                事件玩家 + 上 * 1.500 + 面朝方向(事件玩家) * -4,
                事件玩家 + 面朝方向(事件玩家) * 1000,
                0);
            事件玩家.AE = 1;
        Else;
            停止镜头(事件玩家);
            事件玩家.AE = 0;
        End;
        等待(1, 无视条件);
    }
}
```

## 可套用模板（全部来自实测机制，2026-10-20）

> 写新规则时从这里抄骨架，不要临场发挥。每条下方注明对应机制。

### 1. HUD 显示（建一次，变量自动刷新）

```
规则("HUD")
{
	事件
	{
		持续 - 每名玩家;
		双方;
		全部;
	}

	动作
	{
		创建HUD文本(事件玩家, 自定义字符串("标题"), 空, 自定义字符串("击杀 {0}", 全局.killCount), 左边, 0, 颜色(黄色), 颜色(白色), 颜色(绿色), 字符串, 默认可见度);
	}
}
```

机制：HUD 文本里的变量引用会自动刷新，**只建一次**；重复创建会堆叠成多行（实测 4 次击杀 → 4 行）。

### 2. 周期逻辑（While + 等待）

```
规则("周期")
{
	事件
	{
		持续 - 全局;
	}

	动作
	{
		While(真);
			// 每 0.1 秒执行一次
			等待(0.100, 无视条件);
		End;
	}
}
```

机制：`持续` 规则只执行一次，必须 `While(真)` 撑住；`等待` 第二参数只能 `无视条件` / `当为“假”时中止`，不能填条件表达式。

### 3. 事件驱动计分（推荐，优于轮询）

```
规则("计分")
{
	事件
	{
		玩家造成最后一击;
		双方;
		全部;
	}

	动作
	{
		修改全局变量(killCount, 加, 1);
		修改玩家变量(事件玩家, streak, 加, 1);
	}
}
```

机制：事件驱动不用循环，天然每帧安全；自伤 `伤害(自己, 自己, 1000)` 也会触发「玩家阵亡」。

### 4. 条件等待（自己写循环）

```
动作
	{
		While(全局.ready != 真);
			等待(0.100, 无视条件);
		End;
	}
```

机制：没有 `等待直到(条件)` 这种写法，条件等待必须手写循环。

### 5. 数组追加与清空

```
动作
	{
		设置全局变量(arr, 空);
		修改全局变量(arr, 添加至数组, 1);
		修改全局变量(arr, 添加至数组, 2);
	}
```

机制：追加用 `添加至数组`（`加` 是数值加法）；变量初值 0 会占数组第一位，先 `设置全局变量(arr, 空)` 再追加。

### 6. 临时快照（提示文字取值）

```
动作
	{
		设置全局变量(tmpStreak, 事件玩家.streak);
		大字体信息(事件玩家, 自定义字符串("连杀 {0}！", 全局.tmpStreak));
		等待(1, 无视条件);
		设置玩家变量(事件玩家, streak, 0);
	}
```

机制：`大字体信息` 的 `{0}` 延迟求值，先用临时变量快照，否则清零后显示成 0。

### 通用约束

- 变量名 ASCII、≤32 字符、不能数字开头；引用必须带前缀（`全局.X` / `事件玩家.X`）
- `For 全局变量(i, 1, 5, 1)` 终止值不含，控制变量必须先声明
- 开局有约 5 秒倒计时，测时间行为要留 10 秒以上余量
