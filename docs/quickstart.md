# 5 分钟上手

从「装好」到「模式能导进游戏」，四步。

---

## 第 1 步 · 装（1 分钟）

```bash
npx skills add sandsand244263/overwatch-workshop-lite-skills
```

装完后你的 AI 就能读写这个技能的参考资料和执行命令。

**如果你不用命令行**：把这句交给会用的朋友，或者照 README 里的手动安装说明把文件夹放进 skills 目录。

---

## 第 2 步 · 导出一个模式（1 分钟）

在工坊编辑器里：

1. 打开你想检查的模式
2. **Ctrl+A** 全选 → **Ctrl+C** 复制
3. 打开记事本 → **Ctrl+V** 粘贴
4. 保存 → 文件名随便起，**存成 `.txt` 就行**

> **存成 `.txt` 就行**：游戏「复制脚本」是直接放到剪切板的，你在记事本里一贴、保存，就完事了。
> 具体点哪个按钮见 [界面手册](./ui-workflow.md)。
> **编码也随意**：UTF-8、记事本默认的 ANSI(GBK) 都能读。

---

## 第 3 步 · 让 AI 检查（1 分钟）

对 AI 说：

> 检查这个文件：`C:\Users\你\Desktop\我的模式.txt`

你会看到两种结果之一。

### 情况 A：能导入

```
✓ 我的模式.txt：可以导入（12 条提示，不影响导入）
```

**提示不用管**，直接去游戏里导入。

### 情况 B：有问题

```
✗ 我的模式.txt：2 个问题会导致导入失败（另有 5 条提示，可以先不管）

  ── 必改 ──
  第 44 行：范围内玩家 的队伍参数不能写「双方」
      → 改成 所有队伍（或 队伍1 / 队伍2）；「双方」只能用在事件行
```

照「→」后面那句改就行。改完再让它检查一遍。

---

## 第 4 步 · 修好再导入（1 分钟）

如果文件是从游戏导出的、检查报了一堆错，多半是**导出失真**（不是你的错）。
直接说：

> 帮我修一下这个文件

AI 会跑 `fix`：合并折行、把「无」改回「全部禁用」、删掉导出吞掉的值，然后**再校验一遍**。

```
修复：合并折行 0 处，「无」→「全部禁用」24 处，删空值行已删，布尔词 4 处
校验：error 3 → 0，warning 39 → 11
输出：我的模式.fixed.txt
```

拿到 `.fixed.txt`，进游戏导入：

1. 「设置」页 → 右侧「总览」面板 → 点 **「导入设置」**
2. 弹出的窗口里粘贴文本 → 确定
3. **没有成功提示**，看左侧「模式」列表里有没有出现

> 想连规则一起导，就在「设置 → 地图工坊」编辑器里粘贴（「导入设置」只处理设置部分）。
> 完整界面说明见 [界面手册](./ui-workflow.md)。

## 常见问题

### 导入报错，但校验器说没问题

先查 [报错对照手册](./errors.md)——常见报错的「原文 → 原因 → 改法」都列好了。


把游戏里的报错原文贴给 AI：

> 导入时报「第 26 行的"7"之后应有一个游戏模式设置」，怎么改

这类错误的行号会**指向上一行**，AI 知道怎么定位。

### 我怀疑它报错了（误报）

让它生成一份可上报的材料：

```bash
python tools/ws.py report 我的模式.txt --note "导入是成功的，为什么报错"
```

会输出环境信息 + 问题行 + 脱敏片段，直接贴到 issue 就行。

### 文件太大，检查太慢

正常。400 KB 大约 2-3 秒。慢的是 AI 读文件，不是校验器。

### 能不能不装 Python？

不能。校验器是 Python 写的，但**不需要装任何第三方库**，标准库就够。
`python tools/ws.py doctor` 会告诉你环境有没有问题。
