## 方法（关键）

**不用翻译变量编号**——技能数值来自 `0x09E STULoadout` 的**面板行**：

```
0x075 STUHero
  └ m_heroLoadout → 0x09E STULoadout
      └ m_51A1774F[i]                    ← 面板每一行
          ├ m_BE3CC239    行标题（伤害量 / 最大持续时间 / 弹道 …）
          ├ m_displayText 带单位的格式串（米、米/秒、秒、P0 百分比）
          └ 表达式槽 / m_0230ACA2[] → 0x130 STU_A0E5F3ED
                                      ├ m_3E5360A1 基础值
                                      └ m_1B39F279 当前值
```

英雄级属性（生命/护甲/护盾/移速）也在同一张表里，`ability = 英雄属性`。

## 四个必须知道的坑（都踩过）

1. **`m_0230ACA2` 常残留上一行的节点**：岚第 2 行曾因此拿到别人的 75。正确做法是**表达式槽优先**，静态行才用 `m_0230ACA2`。（本表已修正，462 条弃用值留痕）
2. **`m_1B39F279` 为 0 时要取 `m_3E5360A1`**：否则朱诺护盾 150、金驭生命值 100 会读成 0。
3. **英雄属性面板可能空槽**：需回落 loadout 级 `0x130`（补上莱因哈特 400/300、D.Va 200/325 等 22 处）。
4. **同一字段可能多义**（如「弹道」既是尺寸也是速度）：按单位拆名 `弹道` / `弹道·米/秒`，不要合并。

## 使用注意

- 值是**面板值**，不含暴击、距离衰减、护甲减免，别拿来算精确伤害
- 无单位字段（如「伤害强化 0.25」）通常是比例，0.25 = 25%
- 同一技能可能出现多行同名（如「守护天使 范围 30 米 / 60 米」），是不同档位，不是重复

## 排错：`BLTEKeyException unknown key` 不等于缺密钥

第一次跑全量时有 1 个英雄（血律）读不出，报：

```

**但 key 本来就在 keyring 里**：

```

修法：

```bash

```

**教训**：报"未知 key"时，先查 keyring 文件是否存在且被加载，再怀疑密钥缺失。

## 错值修复（2026-10-21 第二轮）

**问题**：行自己的数值槽为空时，会回退到 `m_0230ACA2` 拿到**上一行**的节点，值看起来正常但是错的。

**铁证**：查莉娅「投射屏障」充能次数 = 225，与同行护盾 225 相同 → 两行指向同一个 `0x130`。

**修法**：同一 loadout 内若两行不同字段指向同一 `0x130`，按「节点 `m_name` 自证 → 字段值域自证 → 都不占优就双双置空」定归属；`-0.5` 哨兵行豁免。

**结果**：15 组冲突 / 12 个英雄 / 置空 32 行，表 1965 → **1933** 行（删除行与 `suspect_rows.tsv` 逐条对应，无新增行）。

**连带修掉**：粒子屏障 充能次数 225（跨 loadout 复用同一节点，225 实为护盾量）。

## 「-0.5」不是哨兵值：一场判断错误与修正（2026-10-21 第三轮）

### 错在哪

大量行读到 `-0.5`，且都指向同一个 `00000000125A.130`。此前判断为「该英雄不适用」。
**这是错的**——那个节点是**空壳**：`name` / `description` / 父节点全为 null，`m_values` 只有一个 `-0.5`。

它表示**槽位未赋值**，真实值在别处。

### 真值在哪（三条路径）

| 路径 | 说明 | 例子 |
|---|---|---|
| A | 同一行的表达式树（`m_37A4BBD9`）里还有另一个真实 `0x130` | 西格玛「生命恢复延迟」→ `000000000B0F.130` = 6 秒 |
| B | 表达式树里也没有 `0x130`，值由**共享字节码按最大生命值现算** | 持续生命恢复 |
| C | 资产里根本没有，是全局规则 | 造成伤害时治疗减免 -30% |

### 持续生命恢复：官方用的是公式

```
持续生命恢复 = 10 + 0.05 × 最大生命值（生命+护甲+护盾）
```

六个英雄 **6/6 精确命中**（截图无威能）：

| 英雄 | 最大生命 | 公式算得 | 面板 |
|---|---|---|---|
| 查莉娅 | 550 | 37.5 | 37.5 ✅ |
| 莱因哈特 | 700 | 45 | 45.0 ✅ |
| 士兵：76 | 250 | 22.5 | 22.5 ✅ |
| 天使 | 225 | 21.25 | 21.3（N1 舍入）✅ |
| 西格玛 | 600 | 40 | 40.0 ✅ |
| 路霸 | 750 | 47.5 | 47.5 ✅ |

**硬证据**：查莉娅/莱因哈特/西格玛/路霸的这段字节码**完全相同**（13 字节），士兵/天使两两相同（9 字节），但结果不同 → 数值不可能编码在常量里，只能现算。

> 该值是**推定**（公式拟合 6/6），表里 `evidence` 标注「推定」，查询时显示 `（推定）`。
