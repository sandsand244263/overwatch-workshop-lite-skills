## 技能数值在哪（关键发现）

**不是**从工坊数据、也不是从 `0x01C` 变量表，而是从**技能面板行**：

```
0x075 STUHero
  └ m_heroLoadout → 0x09E STULoadout          ← 每个技能一份（岚 = 0000000001E5.09E）
      └ m_51A1774F[i]                          ← 面板上的每一行
          ├ m_BE3CC239    行标题（伤害量 / 最大持续时间 / 弹道 …）
          ├ m_displayText 带单位的格式串（米、米/秒、秒、P0 百分比）
          └ m_0230ACA2[] → 0x130 STU_A0E5F3ED
                            ├ m_3E5360A1 基础值
                            └ m_1B39F279 当前值
```

一句话：**游戏英雄信息面板上那一行行数字，在资产里就是一行行结构**，标题和单位格式串都在，不需要猜哪个数字对应哪个字段。

英雄级数值（生命值/护甲/护盾）走另一条：`0x09E` 的 6 个引用槽位 → `0x130`。

| 槽位 | 含义 |
|---|---|
| `m_6994A2CF` | 生命值 / 护甲 / 护盾 |
| `m_13EF906E` | 冷却时间 |
| `m_5D621D4D` | 弹匣 |
| `m_8D4E0678` | 装填 |

## 已放弃的路（别再试）

| 路 | 为什么不行 |
|---|---|
| 把 `0x01C` 当资产读 | 全量普查 **1,496,442 个资产，`0x01C` 数量为 0**；`STUIdentifier` 在 OWLib 里是零字段类，编号是**顺序分配**，不是名字哈希 |
| 拿 `0x01C` 做哈希碰撞找名字 | 同上，不是哈希，思路不成立 |
| 从武器组件里找 `110`、`0.13` | 半藏实体浮点数去重后没有这两个值（`guid_probe.txt` 有证据） |

## 使用注意（重要）

1. **`var_id` 不是全局唯一语义**：`00000000F12F.01C` 在同一份数据里既当「伤害量」又当「生命值」。字段含义取决于**所在面板行**，不能脱离上下文按 ID 直接翻译。
2. **同一个技能可能有多个槽位**：裂地重拳有「主值 75 / 变体槽 60」，界面显示的是变体槽。
3. **数值可能是比例**：`-0.5` 表示 -50%，`0.125` 米就是 0.125 m。`m_displayText` 里带单位，优先信它。
4. **别用来算精确伤害**：这是面板值，不含暴击、距离衰减、护甲减免。

## 覆盖缺口

- 技能面板数值只做了 **2 英雄 / 6 技能**（半藏、末日铁拳）——方法是通用的，可批量扩
- 英雄属性缺 5 个：D.Mon、堡垒、朱诺、血律、金驭
- 技能冷却/弹匣覆盖 26 英雄
