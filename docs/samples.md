# 可运行样例（samples）

三个最小完整模式，各自覆盖一类最常见的写法。**都是能通过校验、带房间设置、可直接导入的完整文件**，路径 `tools/probes/samples/`。

用法：需要写类似逻辑时，复制最接近的样例改参数，而不是从零拼规则。

---

## 一、为什么是样例，不是"模板库"

一开始想做「`ws.py template loop` → 吐一段循环代码」。

**这个想法是错的**：同一件事在工坊里有好几种正确写法，取决于模式设计。比如"每 3 秒执行一次"就分三种情况：

| 设计 | 正确写法 |
|---|---|
| 全场共用一个计时器 | `持续 - 全局` + `While(真)` + `等待` |
| 每个玩家各算各的 | `持续 - 每名玩家` + `While(真)` + `等待` |
| 由事件触发（击杀、受伤） | 事件规则，**不写循环** |

单一"模板"会把人往错的那一种上带。所以给的是**样例 + 适用 / 不适用说明**，让人（或 AI）自己认领最接近的那个。

---

## 二、三个样例

### 1. `sample-periodic.ow` — 全局心跳

```ow
规则("心跳")
{
	事件 { 持续 - 全局; }
	动作
	{
		While(真);
			等待(3, 无视条件);
			全局.Seconds = 全局.Seconds + 3;
			大字体信息(所有玩家(所有队伍), 自定义字符串("已过 {0} 秒", 全局.Seconds));
		End;
	}
}
```

- **适用**：全场共享一个计时器（每 3 秒加资源、定时播报、周期性检查）
- **不适用**：每个玩家时间各不相同 → 改用 `持续 - 每名玩家`，否则所有人共用一个计数器
- **要点**：`持续` 规则只触发一次，想循环必须 `While(真)` + `等待`；没有 `等待` 会在一帧内打死循环

### 2. `sample-event.ow` — 事件驱动

```ow
规则("击杀计数")
{
	事件
	{
		玩家造成最后一击;
		双方;
		全部;
	}
	动作
	{
		事件玩家.Kills = 事件玩家.Kills + 1;
		If(事件玩家.Kills >= 3);
			大字体信息(事件玩家, 自定义字符串("{0} 三杀！", 事件玩家));
		End;
	}
}
```

- **适用**：击杀、死亡、受伤这类由游戏事件触发的逻辑
- **不适用**：需要按时间轮询 → 事件不会自己重复触发
- **要点**：事件后面必须跟两个参数行（`双方;` / `全部;`），少一行就报「事件参数不足」

### 3. `sample-countdown.ow` — 条件等待

```ow
规则("倒计时")
{
	事件 { 持续 - 全局; }
	动作
	{
		全局.TimeLeft = 60;
		While(全局.TimeLeft > 0);
			等待(1, 无视条件);
			全局.TimeLeft = 全局.TimeLeft - 1;
			大字体信息(所有玩家(所有队伍), 自定义字符串("剩余 {0} 秒", 全局.TimeLeft));
		End;
		宣布比赛为平局();
	}
}
```

- **适用**：有明确结束条件（限时、血量归零、得分达标）
- **不适用**：需要无限循环 → 条件一开始就是假，整段会被跳过
- **要点**：结束比赛的动作用 `宣告玩家胜利(玩家)` / `宣告队伍胜利(队伍)` / `宣布比赛为平局()`；`比赛结束` 是**值**（查询是否已结束），不是动作
- **实测教训（2026-10-22）**：初版这个样例用的是死斗 + `宣布比赛为平局`，结果**动作执行了、比赛没结束**——因为「宣布比赛为平局」在自由混战里无效。已改成团队死斗
- 三个样例现在都在 `综合` 块里写了 `游戏模式开始: 即时`，否则房间默认「人满开始」，单人测试时比赛根本没开始

## 三、三个坑（写样例时自己踩的）

| 坑 | 现象 | 正确做法 |
|---|---|---|
| 变量名用中文 | 校验器直接报「变量名只能用英文字母/数字/下划线」 | `Seconds` / `TimeLeft` / `Kills` |
| 把 `比赛结束()` 当动作 | 它是值函数，查询"比赛是否已结束" | 用 `宣告玩家胜利(...)` |
| 变量块里塞占位变量 | 报「声明了但从未赋值」 | 只声明真正用到的；`变量 { 玩家: 0: Kills }` 可以不写全局段 |

---

## 四、这些样例怎么被守住

三个文件在 `check-all` 的扫描范围里（`tools/probes/samples/*.ow`），每次回归都会重新校验，防止哪天数据或规则变了它们悄悄失效。

```bash
python tools/ws.py check-all     # 会一并校验这三个样例
```
