# 英雄默认数值（`data/hero-numbers.tsv`）

> 一句话：**设计模式前先查原值**——改血量前知道基础值、算 DPS 要知道射速、调冷却前知道默认几秒。
> 这张表**不参与校验**：不进 `lint()`、不产生任何错误提示，只在 `ws.py stats` / `ws.py nums` 里被查。

## 怎么查

```bash
python tools/ws.py stats 半藏              # 一个英雄的全部已知数值（属性 + 各技能）
python tools/ws.py stats 半藏 --ability 岚 # 只看某个技能
python tools/ws.py nums --field 射速        # 按字段横查：谁有射速、各是多少
python tools/ws.py nums --field 冷却 --conf 已解析   # 只信已经解析的
python tools/ws.py nums --list-fields       # 看有哪些字段、各多少行
python tools/ws.py stats 半藏 --json        # 结构化输出（给脚本用）
```

## `confidence` 五档（读表第一件事）

| 值 | 含义 | 该不该信 |
|---|---|---|
| `已解析` | 客户端 154905 导出（面板行 / loadout 级 0x130），或**实机面板读数** | 直接用 |
| `推定` | 公式推算，或第三方（overlab.cn，`note` 里带原始串） | 可用，但注明出处 |
| `存疑` | 值读到了但归行判不了，或与补丁记录冲突未裁决 | 别当定论 |
| `缺失` | 面板有这一行，但行内没有取值槽（游戏根本不显示数字） | 当"没有这个数" |
| `未解析` | 槽位是占位节点（`-0.5`），值在运行时表达式里 | 同上 |

**空 `value` 是合法状态**：读到空说明"这个数我们不知道"，不要当 0 用（D-088）。

## 裁决顺序（同一字段多源冲突时）

```
实机读数 > 本次客户端导出 > 官方补丁记录 > 第三方（overlab 等）
```

这条不是理论：2026-11-04 同一天里出现过两种反向情形——安娜生物手雷补丁写 90→60 但游戏仍是 90（资产对、补丁错），
黑影在线修复补丁写 12→10、游戏是 10（资产旧、实机对）。单靠任何一源都会错（D-098）。

## 覆盖边界（说清"没有什么"）

- **有**：生命值/护甲/护盾、移动速度、伤害、治疗、冷却、持续时间、半径、射程、弹道（尺寸/速度/衰减）、
  射速、弹药、击退速度、散布、**终极技能充能消耗**、角色被动常量（重装三条、铁壁/战术/斗士/先锋等）、部分暴击系数。
- **没有/不全**：
  - 面板不显示数字的字段（击退距离、位移速度、焚身焰百分比…）——约 150 行标 `缺失`
  - 少数占位节点（运行时表达式算出来的）——8 行标 `未解析`
  - 面板外的运行时覆盖值：游戏可能把某值改在运行时，静态导出拿不到（黑影案例）
  - 只覆盖国服 154905；换版本要重新生成

## 改这张表的规矩

1. **只补缺、不覆盖**：第三方独有字段并入时不动已有值（D-099）。
2. **每行必须带 `confidence`**，且只允许五档；写不清来源的行不许进表。
3. **单位要归一**：射速统一「次/秒」（源里的"秒/次"取倒数，D-092）；百分比写数字 + `%`。
4. 面板值与新导出冲突时，先看官方补丁记录，再实机；裁决结果写进 `note`，不要静默改数。
5. 这张表**不许**接进 `lint()` 当校验依据——它是参考资料，不是规则。

## 第三方对照（可重复跑）

两件事分开：**拉**（`fetch_weirdgloop.py`）和**比**（`compare_external.py`）。都能重复跑，都只出报告不改表。

```bash
python tools/fetch_weirdgloop.py --kind all --out C:/owdump/wg-cache       # 首次约 1 分钟，之后走缓存
python tools/compare_external.py --cache C:/owdump/wg-cache --out C:/owdump/wg-compare
python tools/compare_external.py --cache C:/owdump/wg-cache --out C:/owdump/wg-compare --hero 莱因哈特
```

`--refresh` 才会重拉；默认命中缓存只重建，几秒完事。

### 拉回来的是什么

| 产物 | 内容 |
|---|---|
| `params.tsv` | 英雄页模板参数（`health/armor/shield/health6v6/damage/cooldown/fire_rate/projectile_speed…`） |
| `changes.tsv` | 补丁页结构化改动：**日期 + 英雄 + 技能 + from→to + 官方补丁说明链接**（实测 14,420 行 / 359 个补丁页） |
| `raw/*.wiki`、`index.tsv` | 原始 wikitext 与修订时间，离线复查用 |

### 判定口径

| verdict | 含义 | 处理 |
|---|---|---|
| `一致` | 两边相等 | 无 |
| `口径差` | 差值正好 150 且是重装 | 正常：我们=5v5 预设，它=5v5 开放（重装被动 +150） |
| `他们滞后` | 它的补丁日志已改成我们的值，页面字段还停旧值 | **我们对** |
| `冲突` | 口径差和补丁记录都解释不了 | 需实机裁决（D-098） |
| `他们缺` | 第三方没有该英雄页 | 无 |

第一次跑的实测（2026-11-04，54 英雄）：一致 40 / 口径差 7 / 他们滞后 2 / 冲突 4 / 他们缺 1（血律没页）。

- **口径差 7 例坐实了重装 +150**：莱因哈特 400+300=700 vs 250+300=550、路霸 750 vs 600、破坏球 725 vs 575……差值全是 150，说明我们表的"预设职责"口径本身没错。
- **他们滞后 2 例**：毛加护甲（补丁日志写 125→150，我们 150，页面字段还是 125）、飞天猫生命（补丁写 225→200，我们 200，页面字段空着）。这印证了 D-096：第三方会落后于补丁。
- **冲突 4 例待裁决**：D.Mon（我们 425 / 它 525）、拉玛刹（500/375）、渣客女王（525/425）、西格玛（550/450）。差值 100–125 不是重装被动，也不是补丁改过，得看实机面板。

### 第三方源的硬规矩

1. 值只能写 `推定`，永不写 `已解析`（D-089）。
2. `changes.tsv` 是**转录**，不是官方原件；和游戏冲突时以实机为准（已经遇到过两次反向情形，D-096/D-098）。
3. 它只有 5v5 开放 + 6v6 口径，**没有"5v5 预设职责"**——比较前先按 +150 换算重装，否则会把正确数据判成错。
