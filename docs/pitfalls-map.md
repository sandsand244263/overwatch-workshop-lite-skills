# 避坑：地图与模式

> 地图池、时段编号、模式名的写法——写地图相关的东西之前看这篇。

> 总索引见 [pitfalls.md](./pitfalls.md)；报错原文查 [errors.md](./errors.md)。

## 地图变体：以编辑器里能选到的为准（2026-10-23 实机）

`maps.tsv` 里有名字 ≠ 编辑器里能选。两个实测例子：

| 图 | 数据表里 | 编辑器里 |
|---|---|---|
| 釜山 | 釜山 / 釜山城区 / 釜山寺院 / 釜山体育场 / 春节变体 | **只有「釜山」**——它是一张图含三个子区域，不是四张图 |
| 多拉多 | — | 只有 **傍晚 / 夜晚**，没有「早晨」 |

所以生成时：**釜山系一律写「釜山」**；多拉多不要写「早晨」。
清单在 `data/map-not-in-editor.tsv`，`ws.py check` 会对这类写法出提示。

## 地图要有该模式需要的东西（2026-10-22 实测）

`地图工坊室内`（GUID `972777519512064577`）是一间**空房，没有目标点**。

所以不是"它只属于死斗"，而是**缺目标点的模式用不了它**：

| 模式类型 | 能用工坊室内吗 | 原因 |
|---|---|---|
| 死斗、团队死斗、决斗 | ✅ | 不需要目标点 |
| 占领要点、机动推进、攻防阵线 | ❌ | 没有控制点/运载目标，游戏报「无效的地图设置」 |

同理：需要运载目标、需要地图特定机关的模式，都要挑对应的图。

**做法**：写非对战模式时，先不写 `启用地图`，让游戏用该模式默认图；确实要指定，从 `ws.py maps` 里挑该模式支持的那张。

`ws.py scaffold --mode 占领要点` 现在默认不写地图，要指定加 `--map "名称 GUID"`。

**校验器查不出这条**：`data/maps.tsv` 只有地图名和 GUID，没有"哪张图有目标点 / 支持哪个模式"的数据。

## `地图工坊 { … }` 里是作者自定义设置（2026-10-22）

```ow
地图工坊
{
	开局符文刷新次数: 6
	新符文降临间隔: 110
}
```

这些键**不是官方设置项**，是作者自己起的名字，写什么都不会报错。校验器不再拿官方设置键表去比。

## `禁用地图` / `启用地图` 块里是地图名列表

```ow
禁用地图
{
	吉拉德堡
	圣诞节国王大道
}
```

不是 `键: 值`，其中带全角冒号的地图名（如 `圣诞节生态监测站：南极洲`）曾被误当成「设置键」。

## 地图要能跑这个模式（2026-10-22 增补）

`启用地图` 里写错的图，游戏只报「无效的地图设置」，不说是哪张、为什么。规律：

| 模式类型 | 例子 | 需要目标点 |
|---|---|---|
| 占点 / 推车 / 攻防 / 推进 / 闪点 | 占领要点、运载目标、机动推进 | **要** |
| 死斗 / 团队死斗 / 决斗 | 死斗 | 不要 |

工坊自带的 `地图工坊室内 / 岛屿 / 空地 / 绿幕 / 训练靶场` **都是空房间，没有目标点**，
只能跑死斗类。数据在 `data/map-traits.tsv`，校验器据此拦 `error`。
节日变体继承本体（万圣节吉拉德堡和吉拉德堡一样能占点）。

## 每个模式有自己的地图池（2026-10-22 补）

「死斗能用任意图」是错的。游戏「设置 / 地图」页里，**每个模式一组**，组内才是该模式可用的图。

| 模式 | 池子大小 |
|---|---|
| 突击模式 | 49 ≈ 全部（Skirmish 不限图） |
| 团队死斗 / 死斗 / 赏金猎手 | 46-47 |
| 决斗先锋 | 28 |
| 勇夺锦旗 | 17 |
| 攻击/护送 | 11 |
| 运载目标 | 9 |
| 占领要点 | 8 |
| 攻防作战 | 6 |
| 机动推进 | 4 |
| 闪点作战 | 3 |
| 攻防阵线 | 2 |

数据在 `data/map-pools.tsv`。校验器行为：

- **不在池子里** → 提示（截图可能漏行，`--strict` 升为必改）
- **无目标点的图 + 目标类模式** → 必改（实测确认，报「无效的地图设置」）

### 工坊「设置 / 模式」一共 21 个 + 一个「全部」

清单在 `data/mode-list.tsv`。6 个 `（6V6）` 变体在 `.ow` 里**没有对应名字**
（`ruleset_schemas.json` 和全部真实语料里都搜不到 `6V6`），所以地图池按基础名合并；
实测两边池子最多差 1 张图，合并不会误报。

「全部」是总开关（勾上=启用下面所有模式），本身不是模式，不参与地图池判断。

**工坊里选不到的模式**（怪鼠复仇、动感斗球、雪球攻势、剧情任务、英雄精通、镜影守望系列、
幻变交锋系列等）只存在于内部 schema 表，写模式时用不到，不要为它们建池子。

## 地图编号的构成（2026-10-22 实测推导确认）

`.ow` 里 `启用地图` 的第二列是 **`0xD8 << 52 | 变体编号`**：

```
972777519512094292 = 0xD80000000010654  → 变体 0x10654（艾兴瓦尔德·早晨）
972777519512064577 = 0xD80000000009241  → 变体 0x9241（地图工坊室内）
```

- 变体编号来自 `maps.json` 每张图的 `Variations`（时段/天气）
- **同一张图可以有多个合法编号**：真实文件里「哈瓦那」出现过 `…068153`（夜晚）和 `…068154`（早晨）
- `maps.tsv` 里的 `00000000068D.09F` 是**资源路径**，绝对不能写进 `.ow`
- 校验器 `check_map_codes` 会拦掉非 `9727775195` 开头的编号

**注意**：多数地图只共享几个通用变体（早晨/夜晚/傍晚），按变体反推编号会出现重号，
所以自动生成的文件**不一定能被游戏接受**，正式写模式时用编辑器里选的编号。

## 模式名在 `.ow` 里的写法（2026-10-22 实测）

编辑器显示名和 `.ow` 里的块名**不完全一样**，写错会报「之后应有一个游戏模式设置」：

| 编辑器显示 | `.ow` 里写 |
|---|---|
| 攻击/护送 | `攻击护送`（**没有斜杠**） |
| 角斗领域（训练靶场） | `角斗领域 训练靶场`（空格，无括号） |
| 占领要点（6V6） | `占领要点 6v6`（小写 v） |
| 攻击/护送（6V6） | `攻击护送 6v6` |

也就是说 **6v6 在 `.ow` 里是能表达的**（我之前判断错了），只是写成小写 `6v6` 后缀。

## 模式至少要有一张地图（2026-10-22 实测）

在「设置 / 地图」页点「关闭所有」会弹：

> 尚未选择地图，你必须调整或撤销设置改动。

因为**每个模式必须至少选一张图**，全关是不允许的状态。
副作用：想靠「全部关掉再导出」一次性拿到所有地图编号行不通——只能逐张关，留最后一张。

## 启用地图的写法：一行一张图 + 若干时段编号（2026-10-22 用户实测）

```
启用地图
{
    绿洲城                                          只写名字 = 默认时段
    绿洲城 972777519512068154                        只开早晨
    绿洲城 972777519512068154 972777519512068153     早晨 + 夜晚
}
```

- **编号 = 时段**，不是地图身份证。`0xD8<<52 | 变体编号`，变体来自游戏 `Variations`
- 同一编号在不同地图上可能代表不同时段（伊利奥斯的 0x68292 是傍晚，尼泊尔的同名时段叫黎明）
- 编号写错 → 游戏报「无效的地图设置」，且不告诉你错在哪
- **不确定就只写地图名**，一定能导入

### 不是所有地图都有天气（2026-10-22 用户指出）

`maps.json` 的 `Variations` 里混着**不能写进 `.ow`** 的东西，例如釜山的：

| 变体名 | 能写进 .ow 吗 |
|---|---|
| 第24赛季 - 早晨 | ❌ 赛季变体 |
| 阴天 | ❌ 天气，不是时段 |
| 早晨 / 夜晚 | ✅（实测确认过） |

所以：**默认只写地图名**。只有实测导出确认过的时段才写编号，目前确认的有
伊利奥斯 / 尼泊尔 / 漓江塔 / 绿洲城（`data/map-variants-verified.tsv`）。

### 埃斯佩兰萨 / 斗兽场的时段编号是坏的（2026-10-22 实测）

这两张图写任何时段编号都会报「无效的地图设置」，**只写一个编号也失败**。
同模式的「新皇后街」带两个编号可以正常导入——所以不是模式问题，是这两张图自己的数据问题。

| 实验 | 结果 |
|---|---|
| 机动推进 + 埃斯佩兰萨 + 1 编号 | ✗ 无效的地图设置 |
| 机动推进 + 埃斯佩兰萨 + 2 编号 | ✗ |
| 机动推进 + 斗兽场 + 1 编号 | ✗ |
| 机动推进 + 新皇后街 + 2 编号 | ✓ |

**处理**：`data/map-known-bugs.tsv` 记录在案，生成时段时这两张自动降级为「只写地图名」。
