# 报错对照手册

游戏报错只给一句话，不给原因、常常连行号都不对。下面是**实测确认过的对应关系**，按“报错原文 → 真正原因 → 怎么改”排列。

> 行号陷阱：游戏报的行号经常指向**上一行**或**下一个符号**，不是出错的那一处。先用 `ws.py check` 定位，再看游戏报错。

---

## 一、地图相关

### `无效的地图设置`

| 可能原因 | 怎么确认 | 怎么改 |
|---|---|---|
| 这张图**不在该模式的地图池**里 | `ws.py check` 会直接说「不在「占领要点」的地图池里」 | 换成池子里的图；池子见 `data/map-pools.tsv` |
| 时段**编号写错了** | 该图没有这个时段，或编号属于别的时段 | 删掉编号，只写地图名（一定可用） |
| 用了**坏图** | 埃斯佩兰萨、斗兽场写任何编号都失败（游戏数据缺陷） | 这两张只写名字 |
| 子图名字写法不对 | 见下一条 | 见下一条 |

### `第N行的"釜山"之后应有一个地图名称`

原因：`釜山寺院` 这种**带子区域**的名字，游戏先认出「釜山」，把后面的字当成下一段。

| 改法 | 说明 |
|---|---|
| 只写主图 `釜山` | 最稳 |
| 或用编辑器里的实际写法 | 在编辑器选一次，导出看它怎么写的 |

### `第N行的"..."之后应有一个游戏模式设置`

原因：**模式名写错**。编辑器显示名和 `.ow` 里的块名不同：

| 编辑器显示 | `.ow` 里写 |
|---|---|
| 攻击/护送 | `攻击护送`（没有斜杠） |
| 角斗领域（训练靶场） | `角斗领域 训练靶场` |
| 占领要点（6V6） | `占领要点 6v6`（小写 v） |

### `尚未选择地图，你必须调整或撤销设置改动`

原因：在「设置 / 地图」页点了**关闭所有**。每个模式**至少要留一张图**。

改法：别全关；要换图就逐张开关。

## 二、设置与自定义设置

### `每一个地图工坊设置只能被引用一次，且必须有唯一一个名称（忽略空格和大小写）`

原因：`地图工坊设置整数/开关/字符串` 的**自定义名重复**了。

改法：每个自定义设置用独立名字。批量生成时特别容易踩——同名设置写 10 次就报这个。

### `设置「X」不在当前版本的数据表里`

原因：键名过期或拼错（官方改过名）。

改法：`ws.py settings <模式>` 查当前可用键；或 `ws.py explain "报错原文"` 反查。

### `无效的选项`

原因：下拉参数填了不在选项里的值。

改法：`ws.py doc <动作名>` 看该参数的合法选项。

## 三、语法与书写

### `"记入查看器("之后应有一个值`

原因：字符串没包 `自定义字符串(...)`。

```
✗ 记入查看器("[测试] 开始")
✓ 记入查看器(自定义字符串("[测试] 开始"))
```

例外：单独一行写 `"注释"` 是合法的。

### `第44行的"8,"之后应有一个值`

原因：队伍类参数写了「双方」。**「双方」只能用在事件筛选**，动作里要用 `所有队伍` / `队伍1` / `队伍2`。

行号指向的是半径参数，不是真正出错的地方。

### `"1);" 之后应有一个值`

原因：变量赋值**没带域**。

```
✗ i = 1;
✓ 事件玩家.i = 1;      或      全局.i = 1;
```

### `End;` 相关报错

原因：`If` / `While` / `For` 没有配对的 `End;`。

注意：真实导出的文件本身就常缺 `End;` 却能导入，所以校验器默认不查这条（`--strict` 才查）。真报错了再补。

## 四、容量限制

### `总计元素数量超过上限 32768`

`ws.py count 文件.ow` 看估算区间。接近上限时以游戏里「显示诊断结果 → 总计元素数量」为准。

### `单条规则超过 98 KB`

把一条巨规则拆成几条。

---

## 五、怎么快速定位

```bash
python tools/ws.py check 我的模式.ow          # 必改 / 提示 分级
python tools/ws.py check 我的模式.ow --strict  # 更严（会多出 End; 配对、语义检查）
python tools/ws.py explain "无效的地图设置"    # 反查报错文案
python tools/ws.py report 我的模式.ow         # 生成可上报的脱敏片段
```

游戏报错原文可以直接贴给 AI，让它先跑 `check`，再对照本手册。
