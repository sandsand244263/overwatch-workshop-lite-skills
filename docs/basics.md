# 工坊常识（OW2 行为与已知 bug）

这些是「不写进代码就一定会踩」的行为，跟语法无关。

## 设置与文本

- **HUD 会按位置居中**：2.1.0.2.106273 之后 HUD 恢复可用，但同一坐标的多个 HUD 会**相互居中**，想错位显示要调 `排序` 或换坐标。
- **地图文本**（`创建地图文本`）给了位置后，文字是**以该点为中心**显示，不是浮在点上方。
- **小字体信息**（`小字体信息`）在部分情况下可能不显示，重要提示用 `大字体信息` 更稳。
- 小字体与地图文本的**默认字体已变更**，跨版本对不齐是正常的。

## 英雄设置

- **降低最大生命值 + 复活**会让血量超过上限，表现成"打不掉血"。
  对策：用 `设置玩家生命值` 在超过上限时拉回。
- **弹药/最大弹药**设置在部分英雄上失效（不生效，也不报错）。

## 变量与 chase

- **正在被 chase 的变量**，其条件不会中途更新，只有 chase 到达终点才刷新。
  因此 `等待直到(全局.x == 5)` 配合无限 chase（如追到 99999）会**永远不满足**。
- 用 chase 做渐变时，条件判断要留给「到达后」的动作，别写成实时判断。

## 地图变体

- 复制为文本时，地图名后面的数字是**变体序号**（早/晚/节日）。
- **省略该数字 = 启用该地图所有变体**；要固定某一种就带上数字。
- 本地 `data/maps.tsv` 里带的是完整 GUID，等价于"具体变体"。

## 本地实测补充

- `持续` 规则只执行一次；周期逻辑必须 `While(真)` + `等待`。
- HUD 文本里的变量自动刷新，建一次即可；重复创建会堆叠。
- `For` 终止值不含；数组追加用 `添加至数组`；变量初值 0 占数组第一位。
- `等待(时间, X)` 的 X 只能是 `无视条件` / `当为"假"时中止`。
- 打开「查看器」会记录日志并写本地文件，玩法模式里不要常态打日志。
