# 游戏里怎么操作（界面手册）

> 全部来自 2026-10-22 实操 + 截图。**这一步没有别的资料可查，游戏里也不会教。**

---

## 一、导出（把游戏里的模式变成文本）

**推荐用房间设置里的「复制设置」**，它会把**房间设置 + 地图工坊全部内容**一起复制到剪切板。

| 在哪儿点 | 得到什么 | 什么时候用 |
|---|---|---|
| **房间设置 → 总览 →「复制设置」** | **完整模式**（预设/大厅/模式/地图/地图工坊/英雄 全部） | **默认用这个** |
| 地图工坊编辑器 → 「全选」→「复制」 | **只有工坊内容**（规则、变量、子程序），**不含房间设置** | 只想改几条规则时 |

复制完新建一个 txt，`Ctrl+V` 粘进去保存。

> 为什么推荐前者：少了房间设置，导入后模式/地图/英雄配置都会丢，模式大概率跑不起来。

## 二、导入（把文本放回游戏）

1. 回到「设置」页，看右侧的「总览」面板
2. 面板顶部有一排图标按钮，鼠标悬停会显示名字：
   **复制设置 / 分享代码 / 导入设置 / 诊断结果**
3. 点 **「导入设置」** → 弹出「导入游戏设置代码」窗口
4. 把文本粘进去 → 点 **确定**

**导入成功没有提示**，直接看左侧「模式」列表里有没有出现你的模式。

> **「导入设置」是整份一键导入**：房间设置、规则、变量、子程序全部一起进去，不用分两步。

---

## 三、分享（给别人一个码）

1. 「设置」页右侧 → **「分享代码」**
2. 弹窗里选：
   - **创建新的代码** → 得到一个新码
   - **上传至现有代码** → 覆盖更新已有的码（**代码更新新版本就是这么做的**）
3. 把码发给别人，他在「导入代码」里输入即可

---

## 四、预设（临时存放 / 自己测试）

「设置 → 预设」里可以保存当前配置。

| 用途 | 说明 |
|---|---|
| 临时存放 | 存几个版本对比 |
| 测试工具 | 存测试用的骨架 |
| 只在自建房生效 | **预设只能自己创房玩**，不能直接分享给别人 |

想分享还是走「分享代码」。

---

## 五、看元素数量和上限

**房间设置 → 地图工坊 → 「显示诊断结果」**，弹窗里有四个数：

| 指标 | 含义 |
|---|---|
| 总计元素数量 | **最多 32768** |
| 最大规则长度 | 每条规则**不得超过 98 KB** |
| 独特英雄皮肤组合最大数量 | 上限 12 |
| 不在玩家栏位中的机器人最大数量 | 上限 2 |

这是**唯一权威的数字**。`ws.py count` 只是估算（真实文件会偏低 4%~19%），接近上限时以这里为准。

## 六、编辑器右上角的按钮

从左到右：

| 按钮 | 作用 |
|---|---|
| 编辑扩展 | 开关扩展（特效/机器人/弹道），显示可用点数 |
| 编辑变量名 | 批量改变量名（全局 A~Z、玩家 A~Z） |
| 编辑子程序名称 | 批量改子程序名（Sub0~Sub7） |
| 全选 | 选中所有规则（配合复制） |
| 添加规则 | 新建一条规则 |

---

## 七、单条规则 / 单个动作也能复制粘贴

| 对象 | 怎么操作 |
|---|---|
| 整份脚本 | 右上「全选」→「复制」 |
| 单条规则 | 规则左侧的勾选框选中 → 复制 |
| 单个动作 | 动作行右侧的「粘贴」按钮旁边可以复制，也能单独导入 |

这意味着**可以只让 AI 写一条规则或一个动作**，你不用整份替换。

---

## 八、常见误区

| 误区 | 实际 |
|---|---|
| “要存成 `.ow` 才能导入” | 存 txt 就行；`.ow` 只是编辑器插件的习惯后缀 |
| “导入成功会有提示” | 没有提示，看模式列表 |
| “预设可以分享” | 不能，预设只在自建房生效；分享用「分享代码」 |
| “导入设置只导设置、规则要另外粘” | 错。**整份一键导入**，规则一起进去 |
