# 探针：少一个 `End;`，游戏到底拦不拦（1 格）

## 要回答的问题

`docs/format-spec.md` 说 `While / If / Else If / Else / End` 成对，但**游戏导入器到底认不认**这件事一直没实测。
现在的状态：`check` 只在 `--strict` 下报这条（`第 N 行：（strict）这条规则里 If/While/For 开头 1 个，End; 只有 0 个`），
默认级别不报 —— 也就是**默认放一个可能导不进去的文件过去**。

这一格决定这条检查是「提示」还是「必改」。升成必改的条件只有一个：**游戏真的拦。**

## 文件

`endcheck-noend.ow`：一条 `持续 - 全局` 规则，`While(全局.A < 3);` 起了头、**故意不写 `End;`**：

```
动作
{
	等待直到(正在设置 == 假, 60);
	While(全局.A < 3);
		全局.A = 全局.A + 1;
	记入查看器(自定义字符串("[e1] A={0}", 全局.A));
}
```

- 无死循环风险：`A` 从 0 加到 3，条件自然为假。
- 默认 `check` 判「可以导入」（只 1 条隐蔽提示）—— 就是要有意放它过去。

## 三种可能的读数和对应结论

| 导入结果 | 日志（`[e1]` 行） | 结论 |
|---|---|---|
| **报错被拦**（记下文案原文） | 无 | 升必改：这条检查从 strict 挪到默认 error 级 |
| **接受**，A 依次 1、2、3 | 3 行，值 1/2/3 | 保持提示级；`End;` 由解析器在块尾补齐 —— 写进 `pitfalls-runtime.md`（缺 End 不会报错，但收尾位置可能和你想的不一样） |
| **接受**，但日志只有 1 行或规则不跑 | 1 行或 0 行 | 升必改：静默改变了行为，比报错更危险 |

## 怎么导、怎么读

1. 导入 `endcheck-noend.ow`
2. **记下导入时有没有报错弹窗**（有就抄原文，`ws.py locate "原文"` 能指到行）
3. 进比赛跑 10 秒，退到大厅再退游戏
4. `python tools/ws.py readlog --expect-file endcheck-noend.expect.tsv`
   期望表只写一条：`[e1]` 出现 3 次、末值 3（若被拦则理应「未出现」—— 两种都对，看导入有没有报错）

只占用户 2~3 分钟，不用玩，读完就能退。
