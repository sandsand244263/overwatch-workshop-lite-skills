# v15 证据探针：3 个「直接影响玩法对不对」的未知项

一次导入一格，一共 4 个文件（`base` 是对照组）。目标是把三件事从「文档里怎么说」换成「游戏里到底怎么跑」：

1. `b1` 击杀事件挂在每名玩家身上时，一次击杀记给谁、记几次（多人计分能不能这么写）
2. `b2` `本地玩家` 当**读取**目标（`生命值(本地玩家)`）和当**动作**目标（`伤害(本地玩家,…)`）各是什么下场
3. `b3` `等待直到` 等着的时候，条件变真又变假，会不会漏掉这次上升沿

## 怎么跑（约 8 分钟）

游戏 → 工坊 → 逐个导入本目录的 4 个 `.ow` → 点「开始」。

| 文件 | 进去之后做什么 | 站多久 |
|---|---|---|
| `base.ow` | 什么都不用做，看到查看器有一行 `[base]` 就行 | 10 秒 |
| `b1.ow` | 站着别动（15 秒后探针自己补两刀，机器人会互殴） | 45 秒 |
| `b2.ow` | 站着别动（第 12 秒探针会往你身上打 25 点） | 40 秒 |
| `b3.ow` | 什么都不用做，纯计时 | 45 秒 |

每个文件跑完：查看器 → 「将当前记录复制到剪贴板」→ 贴回来。**不用退游戏，不用等日志落盘。**

**被拒的话**：把弹窗那条报错原文照抄给我（照抄，不要改字，不要截图转述）。

**一条硬要求**：`b2` 必须**进比赛**，不能挂在观战位——`本地玩家` 只有在你自己身上才有值，观战位读出来永远是 0，那一格就白跑了。

## 每格在问什么

| 格 | 写法 | 卡在哪 |
|---|---|---|
| `base` | 一行 `记入查看器` | 对照组：它成功才说明后面各格的文件基座没问题 |
| `b1k` | `玩家造成最后一击` 事件里 `事件玩家.k = 事件玩家.k + 1`、全局 `total + 1` | 不知道一次击杀会不会在多个玩家实例上各跑一遍（多人计分会重复加分） |
| `b1p` | `持续 - 每名玩家` 里每 10 秒播报自己的 `k` | 不知道玩家变量是每人一份还是共享 |
| `b2r` | `持续 - 全局` 里 `生命值(本地玩家)` | E-82 读到全 0，但那份探针没在同一文件里放「事件玩家」对照，可能是人不在场 |
| `b2c` | `持续 - 每名玩家` 里 `生命值(事件玩家)` | 对照：证明人在场上、读取链路是通的 |
| `b2a` | `持续 - 全局` 里 `伤害(本地玩家, 本地玩家, 25)` | 不知道伤害到底落没落地（血不掉、事件也不触发，是两种不同的失效） |
| `b3A/B` | `等待直到(flag == 真, 20)`，等 2 秒宽 / 0.2 秒宽的脉冲 | 不知道是「逐帧盯着」还是「低频采样」——低频采样会漏短脉冲，写法就得换成锁存标志 |
| `b3D` | 对照：等一个变真后不再变假的标志 | 它也超时说明探针本身坏了，A/B 的「漏」不算数 |

## 读回来之后怎么判

逐格判据在 `expect.tsv`（「读到的意思」列就是判据）。两条硬规矩：

- **对照组失败 → 该格结论作废**（`base` 挂了、`b2c` 全 0、`b3D` 超时都算），先修探针再重测，不许硬解释。
- **只在读数支持的范围里下结论**：`b1s` 只证明「刀打了」，不代表击杀事件一定触发；`b2r` 是 0 且 `b2c` 有数，才能说「本地玩家 读取失效」。

## 校验

四个文件都过了 `ws.py check`：0 error。`b2.ow` 第 121 行的「伤害目标是本地玩家」提示是**故意留的**——这一格测的就是它到底有没有效果，不是要修。
