## 怎么跑（三步，约 6 分钟）

1. **文件**：本目录 7 个 `.ow`。`base` 是对照组；`p1c` / `p4c` 是阳性对照（**别跳过**，它们失败就说明 p1 / p4 的结论不能用）。
2. **怎么跑**：游戏 → 工坊 → 逐个导入：
   - 被拒的：**把弹窗那条报错原文照抄给我**（照抄，不要改字，不要截图转述）。
   - 导入成功的：**只有 `base` / `p1c` / `p3` 需要点「开始」**，进去看查看器 → 「将当前记录复制到剪贴板」→ 贴回来。
3. **`p4` / `p4c` 只导入，绝对不要点「开始」**。它们里面是 `While(假)`，理论上不会卡，但别赌；
   万一真卡住，直接在大厅强行退出集成，别等。

`p3` 要多做一个判断：**进去站 25 秒，看比赛有没有进结算页**（画面变成结算/胜利界面）。
"没进结算页" 和 "进了结算页" 是两种完全不同的结论，比日志更重要。

## 读回来之后怎么判

逐格判据写在 `expect.tsv` 里（「读到的意思」列就是判据，不在这里再写一遍）。
两条硬规矩：

- **对照组失败 → 该格结论作废**，先修探针再重测，不许硬解释。
- **只在读数支持的范围里下结论**：`p3` 没进结算页 ≠ 动作有效；`p4` 导入成功 ≠ 「循环缺等待」不是问题，只能说静态判不了。
