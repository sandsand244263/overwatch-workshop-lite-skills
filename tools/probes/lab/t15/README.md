# T15 实验：英雄设置 vs 规则初始化，谁说了算

> **结论（2026-10-23 实测）：相乘。**
> 英雄 200% 且规则不设 → 打 100 掉 200；英雄 200% + 规则 50% → 掉 **100**（不是 50、也不是 200）。
> 所以两边同时写时实际倍率 = 两个百分数相乘，「规则覆盖英雄页」是错的直觉。见 E-20 / D-053。

**问题**：同一个属性，一处写在「英雄设置」里（房间/英雄页，`.ow` 的 `英雄` 块），
一处写在规则里（`设置受到伤害` 这类动作），两边同时存在时哪个生效？

- 规则动作**覆盖**英雄设置 → 掉 50
- 两者**相乘** → 掉 100
- 英雄设置**覆盖**规则（规则被忽略） → 掉 200

## 两个文件，各导入一次

| 文件 | 英雄设置 | 规则里做的 | 期望 |
|---|---|---|---|
| `T15-0_基准.ow` | 路霸 受到伤害量 **200%** | 不打修正，直接 `伤害(100)` | 掉 200（如果掉 100，说明英雄设置没生效，见下） |
| `T15-1_对照.ow` | 同上 | 先 `设置受到伤害(本地玩家, 50%)` 再 `伤害(100)` | 50 / 100 / 200 三种，对应三种结论 |

两个文件除了那一行动作完全一样——「一次只改一个变量」。

## 怎么看结果

进游戏（自定义游戏 → 设置 → 导入代码）。房间里已经设好 `游戏模式开始: 即时` + `随机英雄复生: 开启`，点开始就直接进比赛、不用选英雄；规则会等「游戏正在进行中」再打。然后打开**查看器**面板，
底部点「将当前记录复制到剪贴板」，粘贴给我。会看到三行：

```
T15-1 开始：8 秒后打 100 点；英雄受到伤害量=200%，规则再设 50%
T15-1|英雄=200%|规则=50%|打=100|前=700|后=500|掉=200
```

最后那个 `掉=` 就是答案：

| N | 结论 |
|---|---|
| 50 | 规则动作**覆盖**英雄设置（英雄页那 200% 被无视） |
| 100 | 两者**相乘**（0.5 × 2.0），跟房间伤害系数一个道理 |
| 200 | 英雄设置**覆盖**规则，`设置受到伤害` 没起作用 |
| 别的数字 | 还有第三种机制，把数字发回来一起推 |

## 注意

- **不要**在界面上去改「受到伤害量」，值已经写在文件里了；界面改会干扰对照
- 如果 `T15-0` 基准掉的不是 200，说明「受到伤害量」这个英雄键在当前版本没生效力，
  这个实验作废——告诉我，我换一个键（`移动速度` / `受到治疗量`）重做
- 子弹/近战别打自己，实验只认规则里那一次 `伤害()`
