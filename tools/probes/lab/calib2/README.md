# calib2：元素估算的两个盲点（2026-10-24）

目的：把 `count` 剩下两个离群文件（丧尸守桥 −10.8%、搜打撤 −17.8%）拉到可解释范围。
每个文件只改**一个变量**，导入后看「显示诊断结果 → 总计元素数量」，报一个数字即可，不用玩。

| 文件 | 测什么 | 模型现在估 | 怎么判 |
|---|---|---|---|
| `V0_赋值标量.ow` | 对照组：一条赋值 `全局.V = 3` | 3 | 与 V1 相减得到「矢量」这一层的价格 |
| `V1_赋值矢量.ow` | `全局.V = 矢量(1, 2, 3)` | 6 | 若实测 −V0 = 3 → 矢量每个分量 1 元素，现模型对；若 = 2 或 4 → 单价要改（搜打撤里矢量出现 261 次） |
| `K21_子程序含嵌套If.ow` | 子程序里两个 If **嵌套**（K20 是两个平级） | 22 | 若实测 21 → 「每个 If 扣 1」成立（下100层 −694 就对了）；若 22 → 应改成「每条子程序规则扣 1」，下100层偏差从 −5.3% 变 −3.5% |

读数写进 `tools/probes/calib2/measurements.csv`（probe,元素数），再跑 `ws.py calib` 复核 43 样本不回归。
