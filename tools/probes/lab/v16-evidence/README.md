# v16 探针包（一次导入，6 格）

这一包只验**这轮新判据必须靠实机确认的东西**。工具怎么说不重要，看游戏怎么反应。

用户要做的事：把 6 个 `.ow` 逐个「导入」一次（都在 `自定义游戏 → 设置 → 导入代码`），每格只看一个现象，
按最后一列告诉我结果。**不用改文件，不用截图**。

## 为什么 P1/P2 会被工具标「必改」

这两格**就是要验工具说得对不对**：

- 工具说「空事件块导入会被拒」——如果游戏其实能导入，那这条新检查是**误杀**，要撤。
- 工具说「未声明的全局变量会挡导入」——同理，能导入就得把 error 降成提示。

所以 P1/P2 的 `check` 结果本身就是判据的一半，别当成文件写错了。

## 六格

| 格 | 文件 | 干什么 | 看什么 | 怎么算通过 |
|---|---|---|---|---|
| P1 | `P1-empty-event.ow` | 一条规则的 `事件 { }` 是空的 | 能不能导入 | 导入被拒 = 工具判对了；能导入 = 工具误杀，撤这条 |
| P2 | `P2-undeclared-global.ow`（**有混淆，2026-10-26 发现：被拒是因为 `全局:` 段空着，不是因为有变量没声明；隔离测试用 `P2b-undeclared-with-others.ow`**） | 变量块里没有 `g` 的声明，动作里 `设置全局变量(g, 1)` | 能不能导入；能导入的话 P2 那行字会不会打出来 | 同上：被拒 = 判对 |
| P3 | `P3-duplicate-name.ow` | 两条规则都叫「同名」 | 能不能导入；进去后聊天栏里 `P3-第一条/第二条` 是不是**各刷一次**（＝两条都在跑） | 只要告诉我「两条都跑」还是「只跑一条」，用来定这条提示要不要升级成必改 |
| P4 | `P4-no-action-block.ow` | 规则只有 `事件`，没有 `动作` 块 | 能不能导入 | 结果决定这条要不要新增检查（现在工具不报） |

| P6 | `P6-skirmish-slots.ow` | 突击模式 + `自由混战人数上限: 1` | 大厅里有没有提示「大厅设置无效」 | 有提示 = 团队规则对突击模式适用；没提示 = 保持「认不出就不判」 |

## 判读口径

统一两件事：**能不能导入**（通过/被拒/报什么提示），**进去后那行 `记入查看器` 的字有没有出现**。
不需要贴日志全文，一句话就够：`P1 被拒 / P2 能导入 / P3 两条都跑 / …`
